# audit-customer
Sistem Form Audit Customer PT. XYZ adalah platform digital untuk mengotomatisasi verifikasi dan evaluasi data pelanggan. Sistem ini menyederhanakan input form, validasi dokumen, otomatisasi scoring, hingga pelaporan real-time. Dengan alur terstruktur, PT. XYZ dapat mempercepat verifikasi, menjaga akurasi, dan meningkatkan transparansi audit.
